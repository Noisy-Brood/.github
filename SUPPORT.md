# Getting help

- **Your account, the app, or the waitlist:** write to
  **hello@noisybrood.com**. It reaches a person.
- **Something in a public repository does not work:** open an issue on that
  repository.
- **A security problem:** report it privately, as
  [SECURITY.md](https://github.com/Noisy-Brood/.github/blob/main/SECURITY.md)
  says. Never in an issue.
- **What Brood reads, and what it asks Google for:**
  [the privacy page](https://www.noisybrood.com/privacy/) says, and
  [what-brood-reads](https://github.com/Noisy-Brood/what-brood-reads) is the
  code that does it.

Wherever you write, please do not include mail, message headers or anything
else from a mailbox, yours or anyone's.
